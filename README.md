# 部落纪元 / Tribal Age

《部落纪元》是一款在终端里玩的回合制部落生存游戏。你从一小片土地出发，探索大陆、开垦农田、收集木材，带领族人撑过冬天。土地有限，另外两个部落也在不断发展。

用方向键选中地块，按提示探索、占领和建田。一点点扩大领地，让部落吃得饱、住得下，是你最重要的任务。

## 开始试玩

先安装 Go 1.26 或更新版本，然后在项目目录打开终端，运行：

```sh
go run ./cmd/tribal-age play --seed 42
```

`42` 决定新游戏的地图，换成别的整数可以换张地图。有存档时先选择“继续游戏／新游戏／退出”；继续游戏沿用存档的种子，不受这里的数字影响。

地图、部落情况和最近消息会一直显示。选中一格，就能看到这块地能做什么。

**一个月就是一回合。时间不会自己往前走：按 Enter，再按 Y，才会结束这个月。** 每月有 2 个行动点，探索、占领、建田和训练各用 1 点；移动光标、查看信息和调整生产不花行动点。

把窗口开大一些，地图和部落情况会分得更开，看起来也更宽松；太小时，游戏会提示你放大。地图会跟着选中的位置滚动。

## 存档和继续

游戏只有一个存档，放在 `~/.config/tribal-age/save.json`。**只有确认结束月份、完成结算后才自动保存，正常覆盖不会再弹确认。**

- 退出不会补存。读档回到上次结算后的月初，本月尚未结算的探索、建造、生产调整和军令都不会保留。
- 没有存档时直接开新局；有旧档时默认选“继续游戏”，用上下键选择、Enter确认。
- 选择新游戏时才询问是否替换旧档；N、Esc或再次Enter取消，Y确认。确认后先保留旧文件，新局第一次月结成功才真正覆盖。
- 存档损坏或版本不支持时会说明原因，原文件不会被自动丢弃；可以退出，或确认新游戏后在首月结束时替换。
- 写入失败会明确提醒“本月已结算，但自动存档失败”，不会重新结算或偷偷在退出时重试。若仍退出，未成功保存的月份可能丢失。

同一存档同一时间只能开一个游戏实例，异常关闭不会留下需要手动删除的锁文件。目前存档会话支持macOS、Linux等Unix系统。

## 怎么操作

| 按键 | 用途 |
| --- | --- |
| 方向键 / WASD | 在地图上选择地块，不花行动点 |
| E | 探索选中的地块 |
| C | 占领选中的无人地块；接收敌方领土使用军队的 O |
| B | 在选中的自有草原建农田，开工后第 3 次结束月份时完工 |
| T | 打开训练确认，Y 训练士兵 |
| P | 调整生产：方向键或 +/- 改采木数量，0 恢复自动，Enter 应用，Esc 取消 |
| L | 查看领地一览：上下键选择，Enter 定位到地图，Esc 或 L 返回 |
| V | 在领土视图和地形视图之间切换，不花行动点 |
| M | 军队管理：1/2/3 选队，+/- 调人数，Enter 应用，Esc 取消 |
| 1 / 2 / 3 | 选择并定位军队 A / B / C |
| F | 给选中的军队下达前往光标处的行军或进攻令 |
| O / H | 接收军队脚下的敌地 / 撤销军令并驻守 |
| Enter | 打开结束月份确认，Y 才真正结算 |
| ? | 查看帮助，再按 ? 或 Esc 返回 |
| Q / Ctrl+C | 打开退出确认，Y退出；只保留上次月末存档，不保存本月未结算操作 |

选中地块后，屏幕会告诉你它的情况、能做什么、要花多少资源。条件不够时会说明原因，不会扣资源或行动点。结束月份、训练和退出的确认框中，**N、Esc 或再次按 Enter 都表示取消**。

## 地图怎么看

默认是**领土视图：底色看归属，字符看地形**。蓝色是我方，橙色、紫色是另外两个部落；同一部落相邻的地块会连成色块。按 **V** 可以切到地形视图，按森林、草原、水域等地形着色；再按一次返回。图例会跟着切换。

`@` 是你的首都，方括号框住正在选中的地块，例如 `[f]`；彩色时还会反色高亮，让当前位置更醒目。`?` 表示未探索，地形和归属都不会透露。

- 地形：`.` 草原，`f` 森林，`^` 山地，`=` 河流，`~` 海洋。
- 如果终端没有颜色，地图会保留归属字符：`P` 我方、`2/3` 其他部落、`-` 无人；例如 `fP` 是我方森林，`[.@]` 是选中的首都。设置了 `NO_COLOR` 时也使用这种显示方式。
- E 探索和 C 占领无人地都要紧挨自己的领土：上下左右算相邻，斜角不算。军队的行军目标则要紧挨军队。
- 目前只能占领草原和森林；山地、河流、海洋可以探索，但不能占领。
- 开局只看得见自己的首都。探索过的地形之后可以查看，但敌军只在己方领土或军队的一格视野内显示，不会永久追踪。

窗口够高时，右侧会显示「大陆局势（已知）」：数字是实际格数，`#` 条形按当前已知领土最多的一方缩放，小势力也至少留一格。这里只数已经探索的领土，不包含未知地块，也不限于眼前这部分地图。小窗口保留数字摘要，比如「已知领土 我8 2:6 3:?」；图表中的「未知」和摘要中的 `?` 都表示暂无已知领地，不代表那个部落已经灭亡。

军队用 `A1`、`B1`、`A2` 这样的标记显示：字母是军队编号，数字是所属部落。军队可以站在敌地，**旗号不代表土地已经归它所有**；选中后仍会说明地形和土地归属。

## 想看看自己的田都怎么样了

按 **L** 打开「领地一览」，就能一起看到自己的地块：哪些是森林、哪些有农田、哪些还在建，以及本月预计会不会有收成。

农田会显示「已完工」或「建造中 1/3」这样的进度，不用在地图上一块块找。用上下键选中一行，按 Enter 就能回到地图并选中那块地；按 Esc 或 L 直接返回。**查看和定位都不花行动点，也不会推进月份。**

## 新手先做什么

1. 开局光标已选中首都，先按 B 建一座农田。
2. 用方向键选旁边的地块，按 E 探索；找到森林后按 C 占领，有了森林才有持续的木材收入。行动点用完时，按 Enter 再按 Y 结束本月。
3. 再探索并占一块草原，攒够木材后，在那里按 B 建第二座农田。
4. 提前为冬天储粮：冬季农田不产粮。存粮不足会停止人口增长，连续两个月付不起口粮才开始减员。
5. 暂时不必急着训练士兵。训练不会增加总人口，还会减少干活的人手、增加粮耗。

可以先把“养活部落，撑过第一个冬天”当作试玩目标。目前没有统一的通关或获胜条件。

## 粮食够了，想多采木怎么办

按 P 打开生产菜单，把优先采木数量调到想要的数字，边调边看右侧预计收成，再按 Enter 确认。这个安排会一直保持，直到你再改。想恢复自动安排，按 P、0、Enter 即可。

- 只能安排已经占领的森林；人手或森林不够时，就按实际能做到的数量安排，并显示原因。
- 数字不是采木上限；如果种完田还有人手，会继续安排采木。人手充足时，改安排不一定会增加产量。
- 调整安排不花行动点，也不会立刻获得资源；仍然只有确认结束月份才结算本月。
- 右侧会提醒粮食够不够、还能不能增长人口，调整时记得留意。

简单说：粮食够吃、木头不够盖新农田时，可以少种一点田、多砍一点树；快入冬时，再优先把粮食攒起来。

## 人口怎么增长

- **人多、空位足，发展才快**：每月累积增长进度，`1000/1000` 对应 1 名新平民，大部落一月可以新增多人。人口越多，增长潜力越大；接近住满时会自然放慢。
- **先有余粮，再添人口**：本月吃饱后，还要够新增后的人口吃 3 个月。只是安全存粮不够时暂停积累、保留小数进度；真正缺粮或住满时清零，不会囤出一批等着出生的人。新增平民下个月才开始干活和吃粮。
- **土地决定能住多少人**：初始首都的聚落可容纳 30 人，普通地块每格 5 人。比如 `人口：30/35` 表示允许增长到 35 人。聚落留在原地，可被占领；迁都不会免费再造一份承载。超载不会自动死人，容量也不代表粮食一定够吃。
- **人多才能经营更多土地**：每 5 名平民可以经营一格农田或森林，士兵不干活。默认先安排种田，再安排采木，也可以在生产菜单里优先安排采木；冬季农田休耕。占下土地但缺少人手时，那格本月不会产出。
- **饥荒有一个月缓冲**：第一次付不起当月口粮，只停止增长、不减员；连续第二个月及以后缺粮，才按缺粮量减少人口。只要有一个月正常付清口粮，连续缺粮记录就会清零。

右侧状态会一直显示增长进度、安全存粮和人手安排；如果暂时不能增长或地块停产，状态与月末消息会说明原因。

扩地能释放增长空间，但不会自动多产粮。人口上来后也要继续建田，别把暂时充足的库存当作长期够吃。

## 想派军队出去怎么办

先保证粮食供应，再考虑战争。开局已有 5 名士兵，想增加兵力可以按 T、Y 训练；训练只是把平民转成士兵，不会增加总人口。

1. 按 **M**，选一支军队、调整人数，Enter 编组。人数发生变化会花 1 个部落行动点，只能在没有敌军的首都办理；Esc 可取消草稿。
2. 回地图按 **1/2/3** 选军，移动光标到它旁边的一格，按 **F** 下令。目标有可见敌军时就是进攻，否则是行军。
3. 命令不会立即执行，仍要 **Enter、Y** 结束月份。每军每月一条军令，改令不叠加次数；**H** 可以改回驻守。军令不挤占部落每月的 2 个经营行动点。
4. 一次交锋只打一轮，双方同时减员。森林利于防守，补给不好会削弱战力；交锋当月不会移动，即使打空守军，也得下月再进入。
5. 进入敌地还不算占领。下个月按 **O** 下达占领令，月底没有交战干扰才能接收；农田及进度保留，接收当月休整，下个月安排自己的人手经营。不接收人口或敌方国库。

军队依靠与首都连通的己方领土补给，深入或被切断会变成“吃紧”“断供”；持续断供有减员风险。孤立的一格己方土地不是凭空出粮的补给站，远征军也不能在面板里隔空补兵，调整人数须回首都。

首都失守可以迁都；失去全部领土才战败退出。战死会同时减少军队、士兵和总人口，战败剩余人口不算全部战死，也不会自动归入胜方。当前 AI 会守备、反击和补兵，**主动跨大陆远征暂未加入**。

右侧经济预览按当前局势估算，不包含尚未执行的交战、断供和占领结果；以月末战报、生产和粮耗消息为准。

## 当前版本还没做什么
- **没有外交和科技**：暂时不能结盟、交易或研究新能力。
- **没有联网和多人游戏**：另外两个部落由电脑控制。

这还是一个基础试玩版本，玩法和资源数值都还在打磨。
