# 部落纪元 / Tribal Age

《部落纪元》是一款在终端里玩的回合制部落生存游戏。你从一小片土地出发，探索大陆、开垦农田、收集木材，带领族人撑过冬天。土地有限，另外两个部落也在不断发展。

用方向键选中地块，按提示探索、占领和建田。一点点扩大领地，让部落吃得饱、住得下，是你最重要的任务。

## 开始试玩

先安装 Go 1.26 或更新版本，然后在项目目录打开终端，运行：

```sh
go run ./cmd/tribal-age play --seed 42
```

`42` 决定这次开局的地图，换成别的整数可以换张地图。

地图、部落情况和最近消息会一直显示。选中一格，就能看到这块地能做什么。

**一个月就是一回合。时间不会自己往前走：按 Enter，再按 Y，才会结束这个月。** 每月有 2 个行动点，探索、占领、建田和训练各用 1 点；移动光标、查看信息和调整生产不花行动点。

把窗口开大一些，地图和部落情况会分得更开，看起来也更宽松；太小时，游戏会提示你放大。地图会跟着选中的位置滚动。

## 怎么操作

| 按键 | 用途 |
| --- | --- |
| 方向键 / WASD | 在地图上选择地块，不花行动点 |
| E | 探索选中的地块 |
| C | 占领选中的地块 |
| B | 在选中的自有草原建农田，开工后第 3 次结束月份时完工 |
| T | 打开训练确认，Y 训练士兵 |
| P | 调整生产：方向键或 +/- 改采木数量，0 恢复自动，Enter 应用，Esc 取消 |
| L | 查看领地一览：上下键选择，Enter 定位到地图，Esc 或 L 返回 |
| V | 在领土视图和地形视图之间切换，不花行动点 |
| Enter | 打开结束月份确认，Y 才真正结算 |
| ? | 查看帮助，再按 ? 或 Esc 返回 |
| Q / Ctrl+C | 打开退出确认，Y 退出，不保存进度 |

选中地块后，屏幕会告诉你它的情况、能做什么、要花多少资源。条件不够时会说明原因，不会扣资源或行动点。结束月份、训练和退出的确认框中，**N、Esc 或再次按 Enter 都表示取消**。

## 地图怎么看

默认是**领土视图：底色看归属，字符看地形**。蓝色是我方，橙色、紫色是另外两个部落；同一部落相邻的地块会连成色块。按 **V** 可以切到地形视图，按森林、草原、水域等地形着色；再按一次返回。图例会跟着切换。

`@` 是你的首都，方括号框住正在选中的地块，例如 `[f]`；`?` 表示未探索，地形和归属都不会透露。

- 地形：`.` 草原，`f` 森林，`^` 山地，`=` 河流，`~` 海洋。
- 如果终端没有颜色，地图会保留归属字符：`P` 我方、`2/3` 其他部落、`-` 无人；例如 `fP` 是我方森林，`[.@]` 是选中的首都。设置了 `NO_COLOR` 时也使用这种显示方式。
- 探索和占领都要紧挨自己的领土：上下左右算相邻，斜角不算。
- 目前只能占领草原和森林；山地、河流、海洋可以探索，但不能占领。
- 开局只看得见自己的首都，探索过的地方之后就能一直看到。

右侧会显示我方领土和其他部落**已经发现**的领土数量，不包含未知地块，也不限于眼前这部分地图。小窗口会缩成一行，比如「已知领土 我8 2:6 3:?」；`?` 表示暂无已知领地，不代表那个部落已经灭亡。

## 想看看自己的田都怎么样了

按 **L** 打开「领地一览」，就能一起看到自己的地块：哪些是森林、哪些有农田、哪些还在建，以及本月预计会不会有收成。

农田会显示「已完工」或「建造中 1/3」这样的进度，不用在地图上一块块找。用上下键选中一行，按 Enter 就能回到地图并选中那块地；按 Esc 或 L 直接返回。**查看和定位都不花行动点，也不会推进月份。**

## 新手先做什么

1. 开局光标已选中首都，先按 B 建一座农田。
2. 用方向键选旁边的地块，按 E 探索；找到森林后按 C 占领，有了森林才有持续的木材收入。行动点用完时，按 Enter 再按 Y 结束本月。
3. 再探索并占一块草原，攒够木材后，在那里按 B 建第二座农田。
4. 提前为冬天储粮：冬季农田不产粮。存粮不足会停止人口增长，连续两个月付不起口粮才开始减员。
5. 暂时不必急着训练士兵。训练不会增加总人口，还会减少干活的人手、增加粮耗。

可以先把“养活部落，撑过第一个冬天”当作试玩目标。目前没有统一的通关或获胜条件。

## 粮食够了，想多采木怎么办

按 P 打开生产菜单，把优先采木数量调到想要的数字，边调边看右侧预计收成，再按 Enter 确认。这个安排会一直保持，直到你再改。想恢复自动安排，按 P、0、Enter 即可。

- 只能安排已经占领的森林；人手或森林不够时，就按实际能做到的数量安排，并显示原因。
- 数字不是采木上限；如果种完田还有人手，会继续安排采木。人手充足时，改安排不一定会增加产量。
- 调整安排不花行动点，也不会立刻获得资源；仍然只有确认结束月份才结算本月。
- 右侧会提醒粮食够不够、还能不能增长人口，调整时记得留意。

简单说：粮食够吃、木头不够盖新农田时，可以少种一点田、多砍一点树；快入冬时，再优先把粮食攒起来。

## 人口怎么增长

- **先有余粮，再添人口**：连续 3 个月吃得饱，且每个月扣掉口粮后，还够增长后的人口吃 3 个月，就会增加 1 名平民。条件中断，增长进度就从头计算；新增人口下个月开始干活和吃粮。
- **土地决定能住多少人**：首都可容纳 30 人，每多占一格领土就多容纳 5 人。比如 `人口：30/35` 表示现在有 30 人，土地允许增长到 35 人。住满只会停止增长，不会自动死人；土地容量也不代表粮食一定够吃。
- **人多才能经营更多土地**：每 5 名平民可以经营一格农田或森林，士兵不干活。默认先安排种田，再安排采木，也可以在生产菜单里优先安排采木；冬季农田休耕。占下土地但缺少人手时，那格本月不会产出。
- **饥荒有一个月缓冲**：第一次付不起当月口粮，只停止增长、不减员；连续第二个月及以后缺粮，才按缺粮量减少人口。只要有一个月正常付清口粮，连续缺粮记录就会清零。

右侧状态会一直显示增长进度、安全存粮和人手安排；如果暂时不能增长或地块停产，状态与月末消息会说明原因。

## 当前版本还没做什么

> **暂不支持存档和读档。退出游戏或关闭终端后，进度不会保留，再次启动会从头开始。**

- **没有战斗**：虽然能训练士兵，但还不能攻击其他部落。
- **没有外交和科技**：暂时不能结盟、交易或研究新能力。
- **没有联网和多人游戏**：另外两个部落由电脑控制。

这还是一个基础试玩版本，玩法和资源数值都还在打磨。
