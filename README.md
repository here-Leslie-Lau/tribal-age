# 部落纪元 / Tribal Age

《部落纪元》是一款在终端里玩的回合制部落生存小游戏。你要带领部落探索土地、开垦农田、收集木材、扩张领土，让大家吃饱，撑过冬天。

目前是早期试玩版本，通过输入文字命令操作，不是用方向键移动角色。

## 开始试玩

先安装 Go 1.22 或更新版本，然后在项目目录打开终端，运行：

```sh
go run ./cmd/tribal-age play --seed 42
```

`42` 决定这次开局的地图，换成别的整数可以换张地图。

启动后，在 `>` 提示符后输入命令并回车。**时间不会自动流逝，只有输入 `end` 才会进入下个月。** 每个月有 2 个行动点，探索、占领、建农田和训练各用 1 点；查看地图和状态不花行动点。

## 怎么操作

| 命令 | 用途 |
| --- | --- |
| `help` | 查看有哪些命令 |
| `map` | 看看已经探索的地图 |
| `status` | 查看人口、领土容量、人手、增长进度和资源情况 |
| `explore x y` | 探索自己领土旁边尚未探索的一格 |
| `claim x y` | 占领相邻、已探索、无人拥有的草原或森林 |
| `farm x y` | 在自己的草原上开工农田，开工后第三次结束月份时完工 |
| `train` | 从平民中训练 5 名士兵，目前还不能用来战斗 |
| `end` | 结束本月，让电脑部落行动，然后收获资源、消耗粮食 |
| `quit` | 退出游戏，进度不会保存 |

命令里的 `x` 是列，`y` 是行，都从 0 开始：横向为 0–23，纵向为 0–15。首都的坐标会显示在状态里；“相邻”只算上下左右，不算斜角。填错坐标或条件不满足时，游戏会提示原因，不会扣资源和行动点。

## 地图怎么看

地图上每格有两个字符：前面表示地形，后面表示这块地属于谁。例如 `.@` 是我方草原首都，`fP` 是我方森林，`.2` 是部落 2 的草原，`.-` 是无人草原，`??` 表示还没探索。

- 地形：`.` 草原，`f` 森林，`^` 山地，`=` 河流，`~` 海洋。
- 归属：`@` 我方首都，`P` 我方领土，`2/3` 其他部落，`-` 无人。
- 目前只能占领草原和森林；山地、河流、海洋可以探索，但不能占领。
- 开局只看得见自己的首都，探索过的地方之后就能一直看到。

## 新手先做什么

1. 用 `status` 找到首都坐标，先在首都建一座农田。
2. 探索并占领附近的森林，有了森林才有持续的木材收入。
3. 再占一块草原，攒够木材后建第二座农田。
4. 提前为冬天储粮：冬季农田不产粮。存粮不足会停止人口增长，连续两个月付不起口粮才开始减员。
5. 暂时不必急着训练士兵。训练不会增加总人口，还会减少干活的人手、增加粮耗。

可以先把“养活部落，撑过第一个冬天”当作试玩目标。目前没有统一的通关或获胜条件。

## 人口怎么增长

- **先有余粮，再添人口**：连续 3 个月吃得饱，且每个月扣掉口粮后，还够增长后的人口吃 3 个月，就会增加 1 名平民。条件中断，增长进度就从头计算；新增人口下个月开始干活和吃粮。
- **土地决定能住多少人**：首都可容纳 30 人，每多占一格领土就多容纳 5 人。比如 `人口：30/35` 表示现在有 30 人，土地允许增长到 35 人。住满只会停止增长，不会自动死人；土地容量也不代表粮食一定够吃。
- **人多才能经营更多土地**：每 5 名平民可以经营一格农田或森林，士兵不干活。游戏会先安排种田，再安排采木；冬季农田休耕，人手转去采木。占下土地但缺少人手时，那格本月不会产出。
- **饥荒有一个月缓冲**：第一次付不起当月口粮，只停止增长、不减员；连续第二个月及以后缺粮，才按缺粮量减少人口。只要有一个月正常付清口粮，连续缺粮记录就会清零。

用 `status` 可以查看增长进度、安全存粮和人手安排；如果暂时不能增长或地块停产，状态与月末消息会说明原因。

## 当前版本还没做什么

> **暂不支持存档和读档。退出游戏或关闭终端后，进度不会保留，再次启动会从头开始。**

- **没有战斗**：虽然能训练士兵，但还不能攻击其他部落。
- **没有外交和科技**：暂时不能结盟、交易或研究新能力。
- **没有联网和多人游戏**：另外两个部落由电脑控制。
- **没有全屏游戏界面**：现在是输入一行命令、查看一次结果的文字玩法。

这还是一个基础试玩版本，玩法和资源数值都还在打磨。
